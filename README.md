# PKU Hospital Management System

## Overview
The PKU Hospital Management System is a web-based application designed to manage core hospital operations including patient records, appointment scheduling, and billing processes. The system aims to improve efficiency, reduce manual errors, and centralize hospital data management.

## Problem Statement
Traditional hospital management often relies on manual or fragmented systems, leading to:
- Inefficient patient record handling
- Delays in appointment scheduling
- Errors in billing and data tracking

This project addresses these issues by providing a centralized digital platform.

## Objectives
- To digitize patient record management
- To streamline appointment scheduling processes
- To improve accuracy in billing and transaction handling
- To provide a centralized database for hospital operations

## Technologies Used
- Java
- HTML, CSS, JavaScript
- MySQL
- Web-based architecture

## System Architecture
The system follows a client-server architecture:
- Frontend handles user interaction and data input
- Backend processes business logic and communicates with database
- MySQL database stores patient records, appointments, and billing data

## Features
- Patient registration and record management
- Appointment scheduling and tracking
- Billing and payment management
- Data storage and retrieval using relational database
- Basic user interface for interaction

## System Workflow
1. User inputs patient data through the interface  
2. System processes and stores data in the database  
3. Appointments are scheduled and tracked  
4. Billing information is generated and recorded  
5. Data can be retrieved and updated when needed
